# PLAN.md

## User Stories
1. **Incoming Freshman**: As an incoming freshman, I want to ask about enrollment requirements and deadlines so that I can submit my documents on time.
   - *Acceptance Criteria 1*: Answers must clearly list required documents.
   - *Acceptance Criteria 2*: Answers must specify accurate submission deadlines.
2. **Parent**: As a parent, I want to know tuition payment options and installment plans so that I can prepare our family budget.
   - *Acceptance Criteria 1*: Option for installment plans must be clearly explained.
   - *Acceptance Criteria 2*: Accepted payment channels (bank, online, cashier) must be listed.
3. **Registrar Staff**: As registrar staff, I want the bot to decline off-topic queries so that official information is not misrepresented.
   - *Acceptance Criteria 1*: Bot politely declines non-enrollment questions.
   - *Acceptance Criteria 2*: Answers include references/IDs to official FAQ entries used.
